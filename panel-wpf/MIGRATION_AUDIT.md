## Отличия, которые не являются потерей функций

- Старый второй скрытый способ разблокировки по клику на имени пользователя не копируется:
  доступ в новой панели открывается прежним паролем, а не двумя последовательными замками.
- Старое отдельное окно `open_friday_chat` уже не было привязано к кнопке старой панели.
  Его отправка текста на озвучку присутствует в журнале и на Обзоре.
- Старый `_legacy_model_plan` также не привязан к кнопкам: доступный конструктор работает
  без Qwen. Неработавшие/устаревшие ветки не возрождаются.
- Темы Windows старой панели заменены отдельным разделом Оформление с пользовательскими
  цветами и эффектами. Структура окон и декоративные анимации не копируются пиксель-в-пиксель.
- Поиск новой страницы выделяет первое совпадение (не все сразу, как Tk-теги);
  остальные совпадения доступны в отфильтрованном результате.
- C# отвечает за интерфейс; Python остаётся обработчиком существующих функций.
  Это перенос интерфейса, не переписывание STT/TTS/Discord на C#.

## Проверки и границы

Сборка C#; Python imports/syntax; `python -m unittest -v test_panel_features`;
визуальный `FridayPanel.exe --smoke`. Смоук без авторизации проверяет размещение страниц,
не имитирует реальное управление ботом. Протокол авторизации проверяется отдельно
с тестовым паролем только в дочернем процессе, без изменения настроек.
Кики/муты проверяются на заглушках. При проверке не запускаются реальные макросы,
озвучка, перезапуск помощников и изменение автозапуска.
