# Панель EFREN на C# — этап 1

Запуск: `bin/FridayPanel.exe`. Сборка: `powershell -File panel-wpf/build.ps1` из корня проекта.

Главное окно использует WPF из установленного .NET Framework 4.x; Visual Studio, SDK и NuGet для этой сборки не нужны. Интерфейс отделён в `MainWindow.xaml`, логика взаимодействия — в `App.cs`. Стили и анимации редактируются в XAML, затем EXE пересобирается. Голосовые модели не загружаются в процесс интерфейса.

`panel_backend.py` — один дочерний Python-процесс с JSON-запросами через закрытые stdin/stdout, без сетевого порта. Сохраняет существующие JSON-настройки и имена. Изменяющие запросы требуют текущего пароля панели. Завершение помощников выполняется только после проверки их процессов существующими функциями. Закрытие панели не выключает помощников.

На C# перенесены главное окно, основные настройки, имена, статусы, управление процессами и показатели нагрузки интерфейса. Журналы, роли, обучение и диагностика открываются в существующих Python-окнах. Автозапуск и дополнительные настройки пока доступны через кнопку «Прежняя панель». Системные ярлыки и автозапуск старой панели на первом этапе не заменяются.

Показатель памяти/CPU включает WPF и его Python-обработчик; модели и отдельные окна не входят. CPU усредняется за 5 секунд относительно всех логических ядер. `--smoke` проверяет загрузку XAML и статуса, сохраняет скриншот в `runtime/wpf-panel-preview.png`, закрывает окно, не выполняя команд помощников.
