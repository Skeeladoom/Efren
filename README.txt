JARVIS LOCAL — КРАТКАЯ ИНСТРУКЦИЯ

Обычный запуск без VS Code:
1. Открой папку проекта в Проводнике Windows.
2. Дважды щёлкни файл «Панель управления.cmd».
3. В открывшемся меню нажми «Запустить JARVIS».
4. Там же можно запустить или остановить Пятницу — Discord-бота.

В Discord к голосовому боту нужно обращаться «Пятница», а не «Джарвис».
JARVIS — локальный ассистент компьютера; Пятница — отдельный Discord-бот.

В меню есть кнопка «Запускать меню вместе с Windows».
Она добавляет только Control Center в автозапуск. После входа в Windows
появится меню, а JARVIS и Пятницу можно будет запустить кнопками.

Браузеры:
- «Джарвис, открой Хром»;
- «Джарвис, открой Опера Джи Икс»;
- «Джарвис, открой Майкрософт Эдж»;
- «Джарвис, открой браузер» — JARVIS спросит, какой именно;
- «Джарвис, открой браузер по умолчанию» — откроется выбранный в меню.

Простые команды Windows, браузеры, папки, игры и управление окнами
выполняются локально через Python и не запускают Qwen.

Qwen3 4B работает локально через Ollama. По умолчанию он вызывается
только явной фразой «Джарвис, спроси Квена ...».

Голос распознаётся локально через Vosk. Wake-word «Джарвис» должен быть
в той же распознанной фразе, что и команда.

Ручной запуск из терминала при необходимости:
python main.py --resident

Установка зависимостей:
pip install -r requirements.txt
