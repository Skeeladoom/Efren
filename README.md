# EFREN

EFREN — локальная панель управления и голосовые помощники для Windows.

В проекте есть два режима:

- **JARVIS** — локальный помощник для управления компьютером;
- **Пятница** — отдельный Discord-бот, который запускается только в полной установке.

## Lite-версия

Lite предназначена для компьютеров без дискретной видеокарты. Она не содержит Discord-бота, Qwen и RVC, поэтому работает заметно легче. Распознавание выполняется локально на CPU, а голосовой вывод — через Piper.

Модели и Python-окружение не хранятся в GitHub. Их подготавливает скрипт сборки из папки `distribution`.

## Быстрый запуск из исходников

Требуется Windows, Python 3.12+ и PowerShell.

```powershell
pip install -r requirements.txt
python main.py --chat
```

Для постоянного режима:

```powershell
python main.py --resident
```

## Безопасность

Модели, журналы, локальные настройки, токены и окружения исключены через `.gitignore`. Discord-токен нельзя добавлять в исходники или передавать другим пользователям.

## Структура

- `main.py`, `router.py`, `voice.py`, `tts.py` — ядро JARVIS;
- `panel-wpf/` — новая панель управления;
- `distribution/` — подготовка Lite-сборки и проверки;
- `website/` — сайт проекта.
