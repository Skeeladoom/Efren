# Локальная проверка Lite — ещё не публичный выпуск

Тестовая панель:
`distribution/staging-lite-002/panel-wpf/bin/FridayPanel.exe`.

1. Запустить её отдельно от основной панели. Заголовок содержит «Джарвис Lite».
2. При первом входе придумать свой пароль (от 6 символов). Пароль основной
   панели не нужен. Хранится только соль и PBKDF2-хеш в lite-auth.json.
3. Нажать «Запустить» в карточке Джарвиса. Загрузка GigaAM может занять
   несколько секунд. Этот запуск открывает микрофон Windows по умолчанию.
4. Проверить простую фразу, например «Джарвис, который час».
5. Нажать «Остановить». Управление проверяет путь интерпретатора, путь main.py
   и время создания процесса. Не использует имя процесса для массовой остановки.

Если процесс завершился при старте — посмотреть logs/lite-process.log внутри
папки staging. Статус «Запущен» означает живой процесс, а не подтверждённую
готовность распознавания/микрофона. Отдельный статус готовности ещё нужен.

Автоматически проверены: создание пароля, неверный пароль, отказ при повреждённом
файле пароля, чужой/повторно использованный PID, запуск/повторный запуск/остановка
на заглушках процесса; интерфейс WPF и подключение настоящего backend; настоящие
инициализация Джарвиса, синтез Piper и PCM-распознавание GigaAM. В реальных
интеграционных тестах микрофон не открывался, звук не проигрывался, команды
Windows не выполнялись. Проверка живого микрофона остаётся ручным этапом.

Не публиковать staging: это экспериментальная среда со старыми тестовыми
зависимостями и неподписанным манифестом. Для выпуска ещё нужны чистая упаковка,
проверка лицензий, обновлятор/восстановление и тест на другом ПК.
