# Общая Пятница принадлежит владельцу EFREN

Решение пользователя: один общий Discord-бот владельца, не отдельные боты друзей.

- Токен Discord, пароли владельца и секреты сервера никогда не включаются
  в Lite, GitHub Pages, Releases, манифесты и примеры настроек.
- Друзья разговаривают с ботом в Discord. Для этого не требуется запускать
  ещё один экземпляр бота или устанавливать его модели на компьютер друга.
- Панель друзей пока не управляет ботом. Будущий удалённый интерфейс требует
  отдельного HTTPS-сервиса, входа пользователя, проверки его Discord-роли,
  разрешений на каждое действие и возможности отозвать доступ.
- GitHub Pages хранит только сайт, Releases — файлы. Они не запускают бота.
- Если бот работает на компьютере владельца, он доступен только пока этот
  компьютер и процесс бота работают. Круглосуточность требует отдельного хоста.
- Не открывать существующий локальный bridge-порт в интернет. Он не является
  готовым публичным API. Общий токен в клиенте недопустим.

Сетевой доступ и удалённое управление сейчас не реализованы и не включены.
